# Computational profile and reproduction

The runs used Python 3.14.7, NumPy 2.5.4, SciPy 1.18.1, pandas 3.1.0,
Numba 0.68.0, ArviZ 1.3.0 and Matplotlib 3.11.2. Four worker processes ran
with `OPENBLAS_NUM_THREADS=1` and `OMP_NUM_THREADS=1`. One initial compilation
of the DLNS filter took approximately 7.4 seconds in a separate timing probe;
subsequent likelihood evaluations on the 835-observation panel took
approximately 0.0034 seconds apiece in that probe. Times depend on the machine
and concurrent load.

The first DLNS sampling loop took 62.8-64.7 seconds per chain, excluding the
initial compilation/initial likelihood. The first joint-proposal attempt
took 63.4-64.8 seconds per chain under a different random-stream setup;
consult each run JSON for its actual chain times. Total wall time includes
process startup, compilation and serialization. Each iteration evaluates
five basic likelihood proposals and the optional joint proposal. SVNS adds
two parameter blocks and repeated likelihood evaluations per elliptical
slice update; its evaluation counts and chain times are in its run JSON.
There are no HMC divergences because this is not HMC.
The SVNS sampling loops took 311.7-327.4 seconds per chain; the bulk ESS
per sum of chain-loop seconds is reported parameter by parameter. Because
the loops run concurrently, summed wall time is not measured CPU time.

From the worktree root in an environment containing the versions above:

```
set OPENBLAS_NUM_THREADS=1
set OMP_NUM_THREADS=1
python -m unittest discover -s tests\hy_canada -v
python -m src.hy_canada.descriptive
python -m src.hy_canada.experiment --warmup 1000 --draws 2000 --seed-base 41701
python -m src.hy_canada.proposal
python -m src.hy_canada.experiment --warmup 1000 --draws 2000 --seed-base 42701 --joint-proposal results\hy_canada\dlns_joint_proposal.json
python -m src.hy_canada.diagnostics --model dlns
python -m src.hy_canada.sv_experiment --warmup 1000 --draws 2000
python -m src.hy_canada.diagnostics --model svns
python -m src.hy_canada.factor_summary --model dlns
python -m src.hy_canada.factor_summary --model svns
python -m src.hy_canada.volatility_summary
```

These commands overwrite matching output files. The first DLNS command
recreates the pilot parameter draws; generate its proposal before running the
independent-seed joint-proposal command. Compact parameter draws, summaries
and figures are tracked; the much larger SV log-volatility paths and
conditional factor-path draws are local under `results/hy_canada/chains/` and
are ignored by Git. They are regenerated by the commands above. Seeds,
calibrated priors, settings, per-block acceptance and per-chain elapsed times
are saved in the run JSON files. No raw-data or source fingerprint is required.
